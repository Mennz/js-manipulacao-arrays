# Exercicios de array em JavaScript

Serie de exercicios com os metodos de array mais comuns do JavaScript, usando
duas listas de exemplo: alunos e produtos.

## O que pratiquei

- `map` pra transformar um array em outro (nomes, precos com desconto)
- `filter` pra selecionar itens que passam numa condicao
- `reduce` pra chegar num valor unico (soma, media, valor total)
- `find` e `some` pra buscar um item ou checar se existe algum
- `every` pra checar se todos os itens passam numa condicao
- `sort` com copia do array (spread), porque ele muda o original
